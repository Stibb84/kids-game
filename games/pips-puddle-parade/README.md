# Pip's Puddle Parade

A tiny, touch-friendly pond game for young children. Tap the glowing lily pad to help Pip hop to each friend, then tap the nest to find the duckling. There are no timers, scores, or wrong answers.

## Play

Open this directory's `index.html` in a current web browser such as Chrome, Edge, Firefox, or Safari. The game runs locally and does not need an internet connection, an install, or a build step. It works with touch, mouse, and keyboard.

To share it online, deploy the repository to a static host and open `games/pips-puddle-parade/`; `index.html` is this game's entry point.
