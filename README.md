# Kids Game

A collection of small, browser-based games for kids. Each game lives in its own directory under `games/`.

## Games

- [Pip's Puddle Parade](games/pips-puddle-parade/index.html) - Help Pip the frog meet pond friends and find a duckling.

Open a game's `index.html` in a current browser to play it. See that game's README for details.
